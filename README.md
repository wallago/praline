# Build Your Rust Repo like a Lazy Boss

🧱 Praline can build a well made repo for rust project, all within a user-friendly terminal user interface!

---

[![forthebadge made-with-rust](http://ForTheBadge.com/images/badges/made-with-rust.svg)](https://www.rust-lang.org/)

## Tools

Tools are grouped by subject.\
Items marked 🆕 are suggested additions for a well-rounded Rust repo.

### Format

- `rustfmt` — Rust code formatting
- `.editorconfig` — editor-agnostic whitespace/style rules
- `taplo` — TOML formatting 🆕

### Lint

- `clippy` — Clippy linter config (`Cargo.lints.clippy` / `Cargo.lints.rust`)
- `typos` — source spell-checking
- `machete` — unused-dependency detection (cargo-machete) 🆕

### Test

- `codecov` — coverage reporting
- `nextest` — next-gen test runner config 🆕

### Security

- `deny` — dependency / license / advisory bans (cargo-deny)
- `audit` — RUSTSEC advisory scanning (cargo-audit) 🆕
- `SECURITY` — vulnerability disclosure policy 🆕

### Build

- `Cargo` — profiles (`dev` / `test` / `release` / `bench`) & lints
- `rust-toolchain` — pinned toolchain / MSRV 🆕
- `.cargo/config` — build & linker settings 🆕

### Release

- `cliff` — changelog generation (git-cliff)
- `committed` — conventional-commit message linting
- `CHANGELOG` — generated by `cliff` 🆕

### CI / CD

- `workflows.ci` — build / test / lint pipeline
- `workflows.cd` — publish / deploy pipeline
- `workflows.release` — tag-driven release (release-plz) 🆕
- `dependabot` — automated dependency-update PRs
- `labeler` — auto-label PRs by path 🆕

### Git / Governance

- `.github` — `ISSUE_TEMPLATE`, `PULL_REQUEST_TEMPLATE`, `CODEOWNERS`, `FUNDING`
- `.gitignore` 🆕
- `.gitattributes` 🆕
- `CONTRIBUTING` — contribution guide 🆕
- `CODE_OF_CONDUCT` 🆕

### DevOps

- `justfile` — task runner (`nix` / `common` / `rust`)
- `bacon` — background compiler / checker 🆕

### Env

- `flake` — Nix dev shell & reproducible builds (`package` / `claude`)
