# Golden-Reference Repo Hardening Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make every config file in this repo correct, consistent, and best-in-class, since the `repo-builder` TUI emits them verbatim into every generated repo.

**Architecture:** Pure config/workflow/docs changes — no `src/**` edits. Each task fixes or adds one coherent slice (a file or a tool), verified by running the relevant tool and observing its output, then committed.

**Tech Stack:** Rust (edition 2024), GitHub Actions, Nix flake dev shell, `just`, `cross`/musl, `jujutsu` for commits, plus new tooling: `taplo`, `actionlint`, `zizmor`, `cargo-semver-checks`, `lefthook`.

## Global Constraints

- **Project name:** `repo-builder` — no leftover `binsider`/`statement.csv`/`bagels.db` strings anywhere.
- **MSRV / edition:** edition `2024`, `rust-version = "1.85"`.
- **Release target matrix (CI *and* CD, identical):** `x86_64-unknown-linux-musl`, `aarch64-unknown-linux-musl`, built via `cross`. No gnu, no `riscv64`, no macOS/Windows.
- **Default branch:** `main` everywhere (never `master`).
- **Publish tooling:** keep the existing `jujutsu`-based `just publish` recipe unchanged.
- **Commits:** made by the user via `jj commit <paths> -m "<msg>"`; conventional-commit style (verified by `committed`).
- **New tool binaries** go into the flake `ciTools` list (`flake.nix:72`), so they land in both the dev shell and CI shell.
- Do not read or modify `src/**`.


- [ ] **Step 3: Replace the `build` job**

Replace the entire `build:` job with:

```yaml
  build:
    name: Build (${{ matrix.target }})
    runs-on: ubuntu-22.04
    strategy:
      fail-fast: false
      matrix:
        target:
          - x86_64-unknown-linux-musl
          - aarch64-unknown-linux-musl
    steps:
      - name: Checkout the repository
        uses: actions/checkout@v4
      - name: Install Rust toolchain
        uses: dtolnay/rust-toolchain@stable
        with:
          targets: ${{ matrix.target }}
      - name: Install cross
        uses: taiki-e/install-action@v2
        with:
          tool: cross
      - name: Cache Cargo dependencies
        uses: Swatinem/rust-cache@v2
      - name: Build the project
        run: cross build --locked --release --target ${{ matrix.target }}
      - name: Upload artifacts
        uses: actions/upload-artifact@v4
        with:
          name: repo-builder-${{ matrix.target }}
          path: target/${{ matrix.target }}/release/repo-builder
```

- [ ] **Step 4: Verify**

Run: `nix run nixpkgs#actionlint -- .github/workflows/ci.yml`
Expected: no errors.
